Stays on your computer.

Works offline. No accounts, no telemetry, no tracking. The one connection: when you add a link, the app asks that site once for its icon.

One key away.

Every tile carries a number. Press 1 to 9 to open the first nine items in the tab. Ctrl+K, or ⌘K on a Mac, searches every tab.

Moves with you.

All data lives in one folder next to the app. Copy both to a USB drive and your tabs come too. A readable backup is saved after every change.

Everything you open,
arranged your way.

Search across every tab

Type part of a name, file name or web address. Results come from all tabs, each labelled with its own tab. Enter opens the first one.

Stars, and nothing lost

Star items to keep them together in a Starred tab. If a file moves, its tile says Not found until you locate it.

  • TabsGroup items, for example Work, Studio and Home.
  • Drag and dropAdd items from your file manager or browser, or with the Add button.
  • ArrangeDrag tiles to reorder them, or onto another tab to move them.
  • Real iconsSystem icons for apps, files and folders. Site icons for links.
  • Keys 1 to 9Open the first nine items in the tab without the mouse.
  • SearchFind any item in any tab by name, file name or address.
  • StarredKeep favourites together. Each stays in its own tab too.
  • Your own namesRename a tile. The file keeps its name, and you can reset.
  • Rows or tilesOne Size slider: rows that show each item's folder, or tiles with bigger icons.
  • Readable backupA YAML file of all tabs and items, saved after every change.
  • Light and darkPick a theme, or follow the system theme.
  • PortableAll data stays in one folder next to the app.

Download

Windows x64 · .exe

Your tabs and items are saved in a folder next to the app. Move both together.

 macOS Apple silicon · .zip

Osprey Launcher isn’t notarised by Apple, so macOS warns you the first time. Click Done, then open System Settings › Privacy & Security, click Open Anyway and enter your password. You only do this once.

 Linux x64 · .tar.gz

Opens .desktop shortcuts with gio launch. Install GLib if gio is missing.

Want to build it yourself? See the developer notes.
